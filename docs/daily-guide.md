# 毎日の使い方（1枚）

## やることは4つだけ

| いつ | やること | どこで |
|---|---|---|
| 朝 | 「今日の一枚」を**見て、紙に写す**（□の行だけ） | Discord「今日の一枚」 |
| 思いついたら | **話す**（雑でいい。音声でいい） | Claudeアプリの「仕事管理」プロジェクト |
| 終わったら | 「〇〇終わった」と**言う**、または紙の写真を送る | 同じ |
| 見たいとき | **見る**（触らなくていい） | Notion「📒 仕事管理」 |

Notionは見るだけ。足す・直す・消すは、全部Claudeに言う。

---

## 話し方の例

| 言うこと | 何が起きるか |
|---|---|
| 「納屋やばい」 | 「こういうこと？」と案が出る → 番号で選ぶ → 登録 |
| 「燃えるゴミ終わった」 | 完了になる。次の一歩の案が出る |
| （紙の写真） | 斜線の項目を読み取り、「完了にする？」と聞かれる |
| 「今日なにやる？」 | 今日の一枚が出る |
| 「今の状況は？」 | プロジェクトごとの進み具合と次の一歩が出る |
| 「これ明日にする」「〇〇やめる」 | やる日が変わる／確認してから消える |
| 「播種機探して」 | 🤖方針カードが出る →「それで」と言うと、Claudeが調べる |

---

## 困ったとき

| 困りごと | こうする |
|---|---|
| 登録を間違えた | 「さっきのを直して：〇〇」「さっきのを消して」 |
| ちがうものが完了になった | 「戻して」 |
| 朝の一枚が来ない | Claudeアプリで「今日なにやる？」 |
| 持ち越しがたまった | 「持ち越しを整理したい」→ 分ける・やめる・延ばすを一緒に決める |
| Notionが見づらい | 見なくていい。「今の状況は？」と聞けば文字で出る |
| 次に何をすればいいか分からない | 「次なにやればいい？」→ 1つだけ出る |
| Claudeの案が的外れ | 「違う」→ どこが違うか番号で選ぶ |
| Notionを触って変になった | 「Notionが変になった」→ Claudeが見て直す |
| Claudeが自分の作業の話をする | 「仕事管理」プロジェクトの中で聞いているか、Notionがオンかを確かめる |

## 最初の設定（1回だけ）

### claude.aiのプロジェクト「仕事管理」（5分）

表示の名前は、アプリの版によって少しちがうことがある（推測）。

1. claude.ai（スマホのClaudeアプリでも可）の「プロジェクト」→「新しいプロジェクト」。名前は「仕事管理」。
2. プロジェクトの「指示」（プロジェクトの指示を設定）を開き、**`prompts/project-instructions.md` の中身を全部**コピーして貼り、保存する。
3. そのプロジェクトで新しいチャットを開き、入力欄の近くのツールの設定で **Notion** と **Web検索** をオンにする。モデルは **Sonnet 5.5**、エフォートは標準のまま。
4. 「今の状況は？」と送る。納屋・BASE・米作りの3つが出れば成功。

| 起きたこと | 原因（推測） | 直し方 |
|---|---|---|
| Claude自身の作業や予定の話をされた | 「仕事管理」プロジェクトの外で聞いている／指示が保存されていない | チャット画面の上に「仕事管理」と出ているか確かめる。出ていなければ、プロジェクトを開いてから新しいチャットを始める |
| 「Notionにつながっていません」と言われた | そのチャットでNotionがオフ | ツールの設定でNotionをオンにする |
| それでもだめ | — | Claude Codeに「プロジェクトの設定がうまくいかない」と伝える |

## テスト手順（完了の条件②）

claude.aiの「仕事管理」プロジェクトで、新しいチャットを開いて順に送る。

| # | 送る言葉 | こうなれば合格 | 結果 |
|---|---|---|---|
| 1 | 「今の状況は？」 | 納屋・BASE・米作りの3つが、進み具合と次の一歩付きで出る | ✅ 11/25 |
