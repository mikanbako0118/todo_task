# 毎日の使い方（1枚）

## やることは4つだけ

| いつ | やること | どこで |
|---|---|---|
| 朝 | 「今日の一枚」を**見て、紙に写す**（□の行だけ） | Discord「今日の一枚」 |
| 思いついたら | **話す**（雑でいい。音声でいい） | Claudeアプリの「仕事管理」プロジェクト |
| 終わったら | 「〇〇終わった」と**言う**、または紙の写真を送る | 同じ |
| 見たいとき | **見る**（触らなくていい） | Notion「📒 仕事管理」 |

Notionは見るだけ。足す・直す・消すは、全部Claudeに言う。

---

## 話し方の例

| 言うこと | 何が起きるか |
|---|---|
| 「納屋やばい」 | 「こういうこと？」と案が出る → 番号で選ぶ → 登録 |
| 「燃えるゴミ終わった」 | 完了になる。次の一歩の案が出る |
| （紙の写真） | 斜線の項目を読み取り、「完了にする？」と聞かれる |
| 「今日なにやる？」 | 今日の一枚が出る |
| 「今の状況は？」 | プロジェクトごとの進み具合と次の一歩が出る |
| 「これ明日にする」「〇〇やめる」 | やる日が変わる／確認してから消える |
| 「播種機探して」 | 🤖方針カードが出る →「それで」と言うと、Claudeが調べる |

---

## 困ったとき

| 困りごと | こうする |
|---|---|
| 登録を間違えた | 「さっきのを直して：〇〇」「さっきのを消して」 |
| ちがうものが完了になった | 「戻して」 |
| 朝の一枚が来ない | Claudeアプリで「今日なにやる？」 |
| 持ち越しがたまった | 「持ち越しを整理したい」→ 分ける・やめる・延ばすを一緒に決める |
| Notionが見づらい | 見なくていい。「今の状況は？」と聞けば文字で出る |
| 次に何をすればいいか分からない | 「次なにやればいい？」→ 1つだけ出る |
| Claudeの案が的外れ | 「違う」→ どこが違うか番号で選ぶ |
| Notionを触って変になった | 「Notionが変になった」→ Claudeが見て直す |

---

## 最初の設定（1回だけ）

1. claude.aiのプロジェクト「仕事管理」を作り、`prompts/project-instructions.md` の枠の中を貼る（手順はそのファイルの上に書いてある）。
2. Discordに「今日の一枚」チャンネルを作り、Webhook URLをClaude Codeに渡す → Claude Codeが朝の秘書を登録する。

---

## テスト手順（完了の条件②）

claude.aiの「仕事管理」プロジェクトで、新しいチャットを開いて順に送る。

| # | 送る言葉 | こうなれば合格 |
|---|---|---|
| 1 | 「倉庫を片付けたい」 | 解釈かゴール案が2〜3個、番号付きで出る |
| 2 | （番号を1つ選ぶ） | タスクが最大7件、1件目が15〜30分の次の一歩。担当・期限の案付き。「登録していい？」と聞かれる |
| 3 | 「はい」 | Notionの🗺全体マップに「倉庫の片付け」の帯が増える。🗂ボードの「これから」にタスクが増える |
| 4 | 「納屋を片付けたい」 | 「納屋の片付けはもうあります。続きにする？」のように、重複に気づく |
| 5 | 「燃えるゴミ終わった」 | 「入口の燃えるゴミだけ袋に入れる」が完了になり、納屋の次の一歩の案が出る |
| 6 | 「今日なにやる？」 | 朝の一枚と同じ形で出る |

※依頼書の条件は「納屋を片付けたい」で通すこと。ただ、納屋はテストデータにもう入っているので、新しく登録する流れは「倉庫」で試し、「納屋」では重複に気づくかを試す。
