2026-11-25 作成。「仮」と書いたところは、決めなくても進められるので仮決めしたもの。直したいところがあれば言ってください。

## 結論（3行）

- **シオンがやることは4つだけ**：話す・見る・紙に写す・終わったと言う。登録・分解・催促はすべてClaude。
- **Notionはデータベース2つ**（プロジェクト／タスク）。アイデアもタスクDBの「状態」で受ける。ビューは4つ。
- **毎朝7時ごろ**、Discordの専用チャンネルに「今日の一枚」（最大5件）が届く。それを紙に写して動く。

## ② NotionのDB設計

### 全体の形

```
📒 仕事管理（ページ）  ← ここを開けば全部見える「ホーム」
 ├─ ☀️ 今日          （タスクDBのビュー）
 ├─ 🗺 全体マップ     （プロジェクトDBのビュー）
 ├─ 🗂 ボード         （タスクDBのビュー）
 ├─ 📁 プロジェクト   （DB本体）
 └─ ✅ タスク         （DB本体）

   📁 プロジェクト  1 ──── 多  ✅ タスク
   （納屋の片付け）          （燃えるゴミだけ袋に入れる／金属ゴミを集める／…）
```

### 📁 プロジェクトDB（9列）

| 列 | 種類 | 中身 | 入れる人 |
|---|---|---|---|
| 名前 | タイトル | 例「納屋の片付け」 | Claude |
| 領域 | セレクト | 御伽荘／農業／個人／藝術農民 | Claude |
| 状態 | セレクト | 構想／進行中／保留／完了 | Claude |
| ゴール | テキスト | 終わったら何が目に見えるかを1行で | Claudeが2〜3案 → シオンが選ぶ |
| 開始日 | 日付 | 始めた日 | Claude |
| 期限 | 日付 | 目安でよい（タイムラインに帯を出すため必須） | Claudeが案 → シオンが選ぶ |
| タスク | リレーション（DB同士のつながり） | タスクDBと自動でつながる | 自動 |
| 進捗率 | 数式 | 完了したタスク ÷ アイデア以外のタスク | 自動 |
| 次の一歩 | 数式 | 「次の一歩」に印が付いた未完了タスクの名前を表示 | 自動 |
| サイン | 数式 | 🔴期限切れ／🟡遅れ気味／💤止まっている／⚠️次の一歩なし | 自動 |

※「タスク」列は関連付けで自動的にできる列なので、実質的に人が意識するのは9列。

**状態の意味**

| 状態 | 意味 | 例 |
|---|---|---|
| 構想 | まだ始めていない大きなアイデア | 久目の無人販売 |
| 進行中 | 動かしている | 納屋の片付け |
| 保留 | 自分の意思で止めている（季節待ちなど）。催促しない | 冬の間の田んぼ作業 |
| 完了 | 終わった | |

「保留」を置く理由：止めているのに毎朝「止まっています」と言われると、見るのが嫌になるため（推測）。

### ✅ タスクDB（12列。ふだん見えるのは6列）

| 列 | 種類 | 中身 | 入れる人 | ふだん |
|---|---|---|---|---|
| 名前 | タイトル | 「対象＋具体的な動作」。例「入口の燃えるゴミだけ袋に入れる」 | Claude | 見える |
| プロジェクト | リレーション | 1つ。単発のことや、まだ行き先のないアイデアは空でよい | Claude | 見える |
| 状態 | セレクト | 💡アイデア／これから／進行中／待ち／完了 | Claude | 見える |
| 次の一歩 | チェックボックス | **1プロジェクトに1つだけ**印を付ける | Claude | 見える |
| やる日 | 日付 | 「今日の一枚」に載せた日 | 朝の秘書・Claude | 見える |
| 期限 | 日付 | 守らないと困る日だけ入れる | Claude | 見える |
| 目安時間 | セレクト | 15分／30分／1時間／2時間以上 | Claude | 見える |
| サイン | 数式 | 🔴期限切れ／🟠持ち越しN日／💤止まっている | 自動 | 見える |
| 担当 | セレクト | シオン（後でメンバーを足せる） | Claude | 隠す |
| 出どころ | セレクト | チャット／音声／紙／Discord／ブレスト | Claude | 隠す |
| 完了日 | 日付 | 完了にした日 | Claude | 隠す |
| 最終更新 | 最終更新日時 | 自動 | 自動 | 隠す |

### 叩き台から変えたところ

| 変更 | 理由 |
|---|---|
| タスクの「開始日」→「**やる日**」 | 小さなタスクは「いつ始めるか」より「どの日の一枚に載せたか」が大事。これがあると「持ち越し」が日付だけで自動的に分かる（持ち越し回数の列が要らない） |
| 状態「次にやる」→「**これから**」 | 「次の一歩」と言葉が似ていて、Claudeもシオンも混ざりやすい |
| 「次の一歩」を**タスク側のチェック**にした | プロジェクト側に文字で書くと、タスクと二重になってずれる。印方式なら、完了した瞬間に「⚠️次の一歩なし」が自動で出る |
| 「停滞」の数式 →「**サイン**」1列にまとめた | 期限切れ・持ち越し・停滞を別々の列にすると列が増える。1列に絵文字で出す |
| 「完了日」を足した | 「最終更新」は何かを直すたびに変わるので、「いつ終わったか」が分からなくなる。仕事ノートの「できた数」にも使う |
| 担当は「人」ではなく**セレクト**（仮） | Notionの「人」の列は、Notionに招待した人しか選べない。メンバーはNotionを使わない前提なので、名前の選択肢にしておく |
| プロジェクトの状態に「保留」を足した | 上の「状態の意味」を参照 |

### アイデアの置き場：タスクDBの「💡アイデア」で受ける（別のDBは作らない）

| | A：タスクDBの状態「アイデア」（採用） | B：別のDB「アイデア箱」 |
|---|---|---|
| Claudeが扱うDB | 2つのまま | 3つになる |
| アイデア → タスクにするとき | 状態を変えるだけ | 別のDBへ移し替え（漏れやすい） |
| 探すとき | 1か所 | 2か所 |
| 気をつけること | 普段のビューに混ざる → 「今日」「全体マップ」では隠し、ボードの左端の列にだけ出す | — |

- タスクくらいの大きさのアイデア → タスクDBの「💡アイデア」
- プロジェクトくらいの大きさのアイデア → プロジェクトDBの「構想」
- 流れて消えないように、**14日以上たったアイデアは、朝の秘書が1日1件「やる？やめる？」と聞く**
- やめたアイデアは、確認してからNotionのゴミ箱へ（ゴミ箱から30日は戻せる）

## ③ ビュー設計（4つ）

| # | ビュー | 形 | 一目で分かること | 中身の条件 |
|---|---|---|---|---|
| 1 | ☀️ 今日 | リスト | 今日やること（紙と同じ） | やる日が今日以前・状態が「これから／進行中」。サイン→期限の順 |
| 2 | 🗺 全体マップ | タイムライン（プロジェクト） | どのプロジェクトがいつまでか、どれが遅れているか、それぞれの次の一歩 | 状態が「進行中／保留」。帯の横に 進捗率・次の一歩・サイン。領域でまとめる（仮：Notionのタイムラインで「グループ」が使えるかは組み立て時に確認） |
| 3 | 🗂 ボード | ボード（タスクを状態別） | アイデア〜完了のどこに何がたまっているか | 完了は直近7日分だけ。カードに プロジェクト・目安時間・サイン |
| 4 | 📅 カレンダー | カレンダー（タスクの期限） | 締め切りが集中している週 | 状態が「完了」「アイデア」以外 |

1〜3は「仕事管理」ページに並べて置く（ここだけ開けばよい）。カレンダーはタスクDBの中のタブにする。

**作らないもの**

| 依頼にあったもの | 今回の扱い | 理由 |
|---|---|---|
| 担当別ボード | 作らない（チーム参加時に、ボードのグループを「担当」に切り替えるだけ） | 今は1人なので、全部「シオン」の列に入り、何も分からない |
| タスクのタイムライン | 作らない | 小さなタスクが数十本並ぶと、図として読めない。時間の流れはプロジェクトで見る |

**スマホでは**：「今日」と「ボード」が見やすい。タイムラインはPC向き（推測）。

## ④ ルールの定義

Claude（会話）と朝の秘書は、このルールだけで判断する。

### 次の一歩の基準（全部満たす）

| # | 基準 | 良い例 | ダメな例 |
|---|---|---|---|
| 1 | 15〜30分で終わる | 入口の燃えるゴミだけ袋に入れる | 納屋を片付ける |
| 2 | 範囲が1つ（場所1つ／種類1つ／数1つ） | 商品を**1つだけ**撮影する | 商品写真を撮る |
| 3 | 目に見える動作で終わる | 田植機の相場を**メモに3件書く** | 田植機について調べる |
| 4 | 終わったことが目で見て分かる | 袋が1つできる | 「だいたい片付いた」 |
| 5 | その場で始められる（足りない物があるなら「買う」が次の一歩） | ゴミ袋を1パック買う | （袋がないのに）袋に入れる |

**使わない言葉**：片付ける・整理する・考える・検討する・計画する・準備する・進める（単独で使うとき）。

> 指摘：依頼書の「動詞で始める」は英語の書き方の発想。日本語は動詞が最後に来るので、「**具体的な動作で終わる**」と読み替えた。

**分解の深さ**：最初の1つ（次の一歩）だけを15〜30分にする。ほかのタスクは1時間以内のかたまりでよい。次の一歩が終わったら、次の候補を15〜30分に切り直す。理由：最初から全部を15分単位に刻むと数が膨らみ、見るだけで疲れる（推測）。

### 状態の判定（日付は日本時間）

| 判定 | 定義 | 対象外 |
|---|---|---|
| 🔴 期限切れ | 期限が今日より前で、未完了 | アイデア |
| 🟠 持ち越し | やる日が今日より前で、状態が「これから／進行中」 | 待ち・アイデア |
| 💤 止まっている（タスク） | 進行中のまま3日、または待ちのまま7日、更新がない | |
| 💤 止まっている（プロジェクト） | 進行中なのに、7日間どのタスクも動いていない | 保留・構想 |
| 🟡 遅れ気味（プロジェクト） | 期間の経過割合が、進捗率より30ポイント以上大きい（例：期間の70%が過ぎたのに進捗40%） | |
| ⚠️ 次の一歩なし | 進行中のプロジェクトに、印の付いた未完了タスクがない | 保留・構想 |

### 今日の一枚

- **上限5件**。
- 選ぶ順番：
  1. 期限切れ・今日が期限
  2. 持ち越し（古い順）
  3. 期限が7日以内のプロジェクトの「次の一歩」
  4. ほかのプロジェクトの「次の一歩」（プロジェクトの期限が近い順）
- 持ち越しが5件以上たまったら、新しいものは足さない（自然に「やりすぎ」を防ぐ）。
- 持ち越しが3日以上続いたタスクは、「大きすぎるかも。分ける？やめる？」と聞く。

### 朝の秘書がNotionに書き込むのは「やる日」だけ（仮）

- 今日の一枚に新しく載せたタスクに、やる日＝今日を入れる。これで、Notionの「今日」ビューと紙が一致する。
- 状態の変更・削除・次の一歩の付け替えはしない（シオンが確認できない時間に動くため）。

## ⑤ 毎日の運用フロー

| いつ | シオンがやること | 裏でClaudeがやること |
|---|---|---|
| 朝7時ごろ | **見る**：Discordの「今日の一枚」→ **紙に写す** | 朝の秘書がNotionを読み、今日の一枚を作って送る |
| 日中 | 紙を見て動く。終わったら斜線 | — |
| 思いついたとき | **話す**：Claudeアプリに一言（音声でよい） | ゴール案 → 分解 → 「これで登録していい？」→ 登録 |
| 終わったあと（夜でも翌朝でも） | **終わったと言う**：「〇〇終わった」または紙の写真 | 完了の候補を一覧 → 確認 → 完了・完了日・次の一歩を更新 |
| 全体を見たいとき | **見る**：Notion「仕事管理」か仕事ノート | — |

確認の返事（「1番で」「はい」）は「話す」に含まれる。**4つの操作に収まっている。**

### Discordに届く「今日の一枚」の形（仮）

```
☀️ 今日の一枚　11/26(木)
━━━━━━━━━━━━━━
□ 納屋｜入口の燃えるゴミだけ袋に入れる（15分）🟠持ち越し1日
□ BASE｜送料の設定画面を開いて「全国一律」を選ぶ（15分）🔴11/25まで
□ 米作り｜来年使う田んぼの名前を紙に書き出す（15分）
合計 約45分

❓ これやった？
・米作り｜苗の注文締切をJAに聞く → 待ち8日目。返事きた？
・納屋｜金属ゴミを1か所に集める → 進行中のまま4日。終わった？
・💡 納屋の一角を作業場にする → 15日前のアイデア。やる？やめる？

📌 ほかに
・持ち越しがあと2件（Notionの「今日」に全部あります）

終わったら「〇〇終わった」か、紙の写真をClaudeへ
```

依頼書の5項目との対応：

| 依頼書の項目 | この形での置き場所 |
|---|---|
| 今日の一枚 | ☀️ そのもの |
| 期限切れ・持ち越し | ☀️ の中に🔴🟠で印。5件に入りきらない分は 📌 に件数 |
| 停滞・「これやった？」3件 | ❓ にまとめて3件まで |

まとめた理由：別々の見出しにすると、同じタスクが「期限切れ」「持ち越し」「今日の一枚」に3回出てしまう。**1つのタスクは1回だけ出す**ルールにした。

## テストデータ（ステップ3で入れる。仮）

ビューの見え方（サインの出方を含む）を確かめるための中身。実際の状況とちがうところは、組み立て後に直すか消す。

| プロジェクト | 領域 | ゴール（仮） | 期限（仮） | タスクの例 |
|---|---|---|---|---|
